# Branding

- CineVault colours: ink `#101C3D`, brass `#E0B04F`, white `#F2F4FA`.
- `tmdb-logo.svg`: the TMDB logo for the required attribution, from
  <https://www.themoviedb.org/about/logos-attribution> (use a variant that reads on a
  dark background). The web build includes this folder as `/branding/…`; the footer
  shows the logo.
